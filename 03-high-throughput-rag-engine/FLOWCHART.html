PROJECT 03 TUTORIAL BLUEPRINT

LLM Evaluation Gate

Automated Welch's t-Test RAG Triad Quality Release Gate

🔀 Visual Logic & Control Flow Blueprint
Step 1: Ingest Candidate Benchmark Dataset
src/eval_gate.py -> LLMEvalGate.evaluate_build()
Loads test set questions, candidate outputs, and ground-truth reference answers.
↓
Step 2: Compute Metric Scores (Faithfulness, Groundedness, Toxicity)
src/eval_gate.py -> FaithfulnessEvaluator.score()
Calculates LLM-as-a-Judge numerical metric scores across candidate output samples.
↓
Step 3: Execute Welch's t-Test Hypothesis Testing
src/eval_gate.py -> WelchTTestScorer.compare()
Computes Welch's unequal variances t-statistic and p-value against production baseline scores.
↓
Decision 1: Is p-value < 0.05 AND Mean Delta > Minimum Threshold?
Condition Branch
Validates statistical significance of quality improvement.
✔ CONDITION TRUE: Pass Metric Gate
✖ CONDITION FALSE: Fail Release Gate
↓
Step 5: Check Toxicity Policy Enforcement
src/eval_gate.py -> ToxicityEvaluator.check_safety()
Ensures zero samples exceed toxicity threshold score of 0.05.
↓
Decision 2: All Metrics Passed Gate?
Condition Branch
Final CI/CD gate evaluation rule.
✔ CONDITION TRUE: APPROVED -> Register MLflow Model Artifact
✖ CONDITION FALSE: REJECTED -> Trigger CI/CD Build Fail & Alert

⚡ Exhaustive Logical Conditionals & Codebase Mapping
Decision 1: Free VRAM Physical Blocks >= Required Blocks?
src/paged_kv_cache.py -> PagedKVCacheManager.allocate_blocks()
Rule Evaluated: Checks available 16-token physical VRAM memory blocks.
✔ DOWN BRANCH (Memory Available): Binds logical token blocks to physical VRAM blocks with zero fragmentation.
✖ LEFT BRANCH (Memory Pressure): Preempts lowest priority sequence, evicts KV blocks to host CPU RAM, and retries allocation.
Decision 2: How Many Speculative Draft Tokens Accepted by Target Model?
src/speculative_verifier.py -> SpeculativeVerifier.verify_tokens()
Rule Evaluated: Evaluates target model logit predictions against draft model speculated K tokens in parallel.
✔ LEFT BRANCH (All K Accepted): Maximum 2.67x generation speedup. Advances sequence position by K tokens.
✖ RIGHT BRANCH (Partial N < K Accepted): Accepts N matching tokens, samples true replacement token, and reclaims invalid draft KV blocks.

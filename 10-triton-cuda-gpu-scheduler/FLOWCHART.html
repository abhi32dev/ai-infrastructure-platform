Triton CUDA GPU Scheduler

Dynamic Batching Queue & AWQ INT4 Quantized Inference Engine

🔀 Visual Logic & Control Flow Blueprint
Step 1: Inference Request Arrival
src/triton_engine.py -> TritonGPUScheduler.enqueue_request()
Pushes incoming request payload into Dynamic Batching Queue.
↓
Step 2: Dynamic Batch Collector & Delay Evaluation
src/triton_engine.py -> DynamicBatchingQueue.collect_batch()
Waits up to max_queue_delay_ms (10ms) or until batch size reaches max_batch_size (32).
↓
Decision 1: Batch Ready OR Max Delay Expired?
Condition Branch
Evaluates batch forming trigger.
✔ CONDITION TRUE: Form Tensor-Aligned GPU Batch
✖ CONDITION FALSE: Wait for Next Request Arrival
↓
Step 4: Execute AWQ INT4 Matrix Multiplication Kernel
src/triton_engine.py -> AWQQuantizer.matmul_int4()
Executes INT4 weight unpack and GEMM on CUDA Tensor Cores.
↓
Step 5: Scatter Outputs to Client Streams
src/triton_engine.py -> TritonGPUScheduler.dispatch_results()
Unpacks batch response tensor and streams results back to individual client futures.

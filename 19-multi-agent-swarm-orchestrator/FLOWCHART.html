◆ Decision 1: Was Circular Dependency Cycle Detected in Task Graph?
src/swarm_orchestrator.py → DAGValidator.detect_cycles()
Condition Evaluated: Performs Kahn's algorithm topological sort over task dependency graph to detect circular deadlock cycles.
↙ LEFT FAST-PATH: YES (Cycle Found)
Aborts swarm execution immediately, throwing CycleDeadlockException with offending node dependency list.
↓ DOWN EXECUTION: NO (Clean DAG)
Proceeds to step 2 execution: Dispatch Workers & Aggregate Voting.
◆ Decision 2: Does Agent Voting Consensus Score Reach Majority (Score >= 66%)?
src/swarm_orchestrator.py → ConsensusEngine.evaluate_consensus()
Condition Evaluated: Aggregates output responses from worker agent swarm and calculates majority voting consensus score.
↓ DOWN SUCCESS: YES (Consensus)
Emits verified consensus result payload when >= 66% of swarm agents agree on execution answer.
↘ RIGHT BRANCH: NO (Disagreement)
Triggers exception evaluation to check retry boundary limits.
◆ Decision 3: Is Senior Tie-Breaker Evaluator Agent Configured?
src/swarm_orchestrator.py → ConsensusEngine.has_tie_breaker()
Condition Evaluated: Checks if swarm orchestrator configuration includes a designated senior tie-breaker evaluator agent.
↺ UPWARD RETRY LOOP: YES: Senior Agent
Invokes senior tie-breaker agent to review conflicting worker agent outputs and render final decision.
↓ EXHAUSTED FALLBACK: NO (Failed)
Dispatches conflicting agent output payloads to senior evaluator agent for final tie-breaking decision.

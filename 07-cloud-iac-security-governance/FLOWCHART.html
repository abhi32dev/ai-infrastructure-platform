Cloud IaC Security Governance

🔀 Visual Logic & Control Flow Blueprint
Step 1: Parse CloudFormation / CDK AST
src/cloud_governance.py -> IaCSecurityScanner.scan_template()
Loads IaC template JSON/YAML and parses Abstract Syntax Tree (AST) nodes.
↓
Step 2: Scan IAM Policy Definitions
src/cloud_governance.py -> IAMWildcardAuditor.audit_policies()
Inspects Action and Resource fields for forbidden '*' wildcard permissions.
↓
Decision 1: Are Wildcard IAM Permissions Detected?
Condition Branch
Checks policy rules against least-privilege principles.
✔ CONDITION TRUE: Flag CRITICAL Security Violation
✖ CONDITION FALSE: Pass IAM Audit Check
↓
Step 4: Check S3 / Storage Encryption & Public Access
src/cloud_governance.py -> CDKASTRuleEngine.check_storage()
Verifies KMS encryption flags and public bucket block configuration.
↓
Decision 2: Total Security Violations == 0?
Condition Branch
Final policy compliance gate.
✔ CONDITION TRUE: PASS -> Approve Deployment Pipeline
✖ CONDITION FALSE: FAIL -> Block CI/CD Build & Export Governance Report

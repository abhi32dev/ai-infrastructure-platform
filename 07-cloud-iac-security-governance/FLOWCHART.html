Decision 1: Are Wildcard IAM Permissions Detected?
src/cloud_governance.py -> IAMWildcardAuditor.audit_policies()

✔ LEFT BRANCH (Security Violation): Flags CRITICAL security policy offense.
✖ RIGHT BRANCH (Policy Compliant): Passes IAM audit check and proceeds to storage scan.
Decision 2: Is S3 Storage Unencrypted OR Publicly Accessible?
src/cloud_governance.py -> CDKASTRuleEngine.check_storage()
Rule Evaluated: Verifies KMS encryption flags and public bucket block configuration.
✔ LEFT BRANCH (Storage Violation): Flags HIGH security offense for unencrypted/public bucket.
✖ RIGHT BRANCH (Secure Bucket): Passes storage compliance check.
Decision 3: Total Security Offenses == 0?
src/cloud_governance.py -> IaCSecurityScanner.evaluate()
Rule Evaluated: Evaluates cumulative offense count across all AST security rules.
✔ DOWN RIGHT BRANCH (Clean Audit): Approves IaC deployment pipeline.
✖ DOWN LEFT BRANCH (Offenses Found): Fails security release gate and blocks deployment.

↘ RIGHT BRANCH: NO (Offenses)

↺ UPWARD RETRY LOOP: YES: Auto-Remediate

↓ EXHAUSTED FALLBACK: NO (Violations)
Blocks CI/CD deployment pipeline, exports SARIF security report artifact, and notifies cloud security leads.

◆ Decision 1: Event Timestamp Below 10-Minute Watermark Boundary?
src/event_pipeline.py → WatermarkFilter.is_late_event()
Condition Evaluated: Checks incoming event timestamp against 10-minute Structured Streaming event watermark boundary.
↙ LEFT FAST-PATH: YES (Expired)
Drops late-arriving stream records beyond 10-minute watermark to prevent PySpark state store memory leaks.
↓ DOWN EXECUTION: NO (Valid Window)
Proceeds to step 2 execution: Deduplicate & Execute 3-Pass Storage.
◆ Decision 2: Does Record Pass Data Quality Schema Contract?
src/event_pipeline.py → SchemaContractValidator.validate()
Condition Evaluated: Validates non-null constraints, data types, and primary key uniqueness across transformed PySpark DataFrame.
↓ DOWN SUCCESS: YES (Passed)
Performs atomic ACID append transaction to Delta Lake Gold table and emits OpenLineage job run state event.
↘ RIGHT BRANCH: NO (Corrupt)
Triggers exception evaluation to check retry boundary limits.
◆ Decision 3: Is Dead-Letter Queue (DLQ) Active & Writable?
src/event_pipeline.py → DLQManager.is_writable()
Condition Evaluated: Checks S3 Dead-Letter Queue bucket permissions and storage availability.
↺ UPWARD RETRY LOOP: YES: Retry Buffer
Buffers temporarily failed records in memory queue for automated retry batch processing.
↓ EXHAUSTED FALLBACK: NO (Corrupt)
Writes corrupt or schema-violating records to S3 DLQ quarantine bucket and emits Datadog alert.
